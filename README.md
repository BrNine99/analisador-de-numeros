# 📊 Analisador de Números

Este é um projeto que desenvolvi durante meus estudos de HTML, CSS e JavaScript.

O objetivo do programa é permitir que o usuário adicione números inteiros em uma lista e, depois, faça uma análise desses valores, mostrando algumas informações estatísticas.

Com esse projeto, coloquei em prática alguns conceitos de JavaScript que venho estudando, principalmente funções, arrays, estruturas de repetição, condicionais e manipulação do DOM.

## 🚀 Funcionalidades

O programa permite:

- Adicionar números inteiros a uma lista.
- Visualizar os números adicionados.
- Verificar a quantidade de números informados.
- Calcular a soma dos números.
- Calcular a média dos valores.
- Identificar o maior e o menor número.
- Contar quantos números são pares e ímpares.
- Limpar a lista e os resultados para começar novamente.

Também adicionei uma validação para impedir que o usuário insira valores vazios, letras ou números decimais.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização e organização visual.
- **JavaScript:** lógica do programa, cálculos e interação com o usuário.

## 💻 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador.
4. Digite um número inteiro e clique em **Adicionar**.
5. Depois de adicionar os números desejados, clique em **Analisar números** para visualizar os resultados.
6. Para começar novamente, clique em **Limpar lista**.

Não é necessário instalar nenhuma biblioteca ou dependência.
